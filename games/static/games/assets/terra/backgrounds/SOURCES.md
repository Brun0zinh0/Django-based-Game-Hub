# Battle backdrop sources

The first backdrops here were supplied by the project's author.

The rest are showcase renders from **Backgrounds o' Plenty**, a Terraria
texture pack by **Shashwambam**:

    https://steamcommunity.com/sharedfiles/filedetails/?id=2971754944

The pack itself is not included and is not redistributable from here: Steam's
own API returns an empty `file_url` for it, because workshop content sits
behind a handle only an authenticated client can redeem. What is in this
folder are the public showcase images from that page, which are renders of the
backgrounds the pack draws. Each has had its name plate cropped off, and
`manifest.json` records which render every file came from.

The art is Shashwambam's, built on Terraria, which is Re-Logic's. Neither is
affiliated with this project. Credited in the project README.
