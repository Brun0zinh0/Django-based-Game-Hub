# Music

Drop audio files here to give the games a soundtrack. The folder is the
playlist: files at the top level of a game's `music` folder form its main
playlist, and each sub-folder becomes a named playlist you can pick in the
settings menu.

    sounds/RogueLike Batle royal/music/*.mp3
    sounds/Pokerogue/music/*.mp3

Both games run fine with this folder empty -- they simply play no music.
The tracks used during development are not redistributed here.

Terra Boss does not read this folder: its sound is generated in the
browser, so it needs no files.
